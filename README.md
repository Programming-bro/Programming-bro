### 🩸 RedHeart — Blood Bank Management System

A full-stack blood bank platform designed to connect blood donors and recipients.

**Technologies:**

`React.js` `Tailwind CSS` `Django` `Django REST Framework` `PostgreSQL` `JWT`

**Key Features:**

- 🔐 User authentication & JWT authorization
- 📧 Email verification & account activation
- 🩸 Donor profile management
- 📢 Blood request creation
- 🤝 Donor request acceptance
- 📜 Donation history
- 📊 User dashboard
- 🔌 RESTful API
